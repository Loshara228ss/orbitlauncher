# Orbit Launcher — Red Edition

Next-Generation Minecraft Client & Launcher with Built-in FPS Booster, Modrinth Catalog, Capes Studio, and Multiplayer Hub.

## Features
- **Red & Obsidian Black Theme**: High-performance UI with zero emojis and pure vector SVGs.
- **Orbit FPS Booster (Official Mod)**: Player-controlled Fabric optimization mod.
- **Modpack Export & Import**: 1-click `.orbit` sharing with friends.
- **Shaders & Resource Packs**: Modrinth store integration for mods, shaders, and resource packs.
- **Capes & Cloaks Studio**: 8 classic presets + custom 64x32 cape upload with live 3D physics.
- **Servers & Multiplayer Hub**: Real-time TCP server monitor and 1-click Quick Join for Radmin VPN / LAN.
- **Screenshots Gallery**: Browse in-game captures and copy directly to Windows clipboard.
- **Discord Rich Presence (RPC)**: Native named-pipe presence integration.
- **Account Switcher**: Fast multi-profile switching.
- **Built-in Auto-Updater**: Seamless updates via GitHub Releases.

## Development & Building
```bash
npm install
npm start
npm run dist:installer
```
